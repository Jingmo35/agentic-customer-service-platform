# 语义目标与执行权限

> 原文：[docs/semantic-target-authority.md](../semantic-target-authority.md)。翻译基准：`d2523b0`。本文描述上游参考实现。

对于 `semantic_decision_v2` 和 `semantic_decision_v3`，语义理解不等于执行权限。第 2 版作为历史契约保留。第 3 版在 Pydantic 和函数调用 Schema 中都使用严格的判别式分支，显式表达目标信息是否完整（**根据类型标签区分不同的目标结构**）。

在编译之前，必须以可信的当前用户消息为依据，用确定性的方式对具体订单和工单标识符进行依据校验。用户提供的标识符仍需经过常规的存在性与归属验证。

`latest_order` 等符号引用仍可用于经过身份认证的只读解析。它们不能作为取消订单或退款等破坏性意图的权威目标。这些请求必须澄清，除非包含经过依据校验的显式标识符。这是有意用一部分破坏性请求的便利性，换取更严格的业务状态修改目标边界。
