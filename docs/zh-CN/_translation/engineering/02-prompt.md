# 翻译提示上下文

按 normal 模式将工程文档由英文完整翻译为简体中文，面向初学 Agent 应用开发的实习求职者。使用自然、准确、简洁的技术文档语言。保留段落、列表、表格、标题顺序、代码块、命令和所有数字，不以摘要替代原文，不新增个人实施成果。

统一术语以 `01-analysis.md` 和项目 `.baoyu-skills/baoyu-translate/EXTEND.md` 为准。首次专业术语可保留英文括注。不要翻译变量、函数、API、协议、类名、版本号或代码中的数据。不要将未知写入结果误译为可重试；不要将语义建议等同于执行权限；不要把 D2c 和 D2d 的参考部署评测结果扩大为生产认证。

每个结果保存到指定 `docs/zh-CN` 同名文件，添加来源相对链接和基准提交 `d2523b0`。修复移动后链接；仅在已知目标标题匹配时保留锚点。英文源文件不修改。最终对照检查标题数量、代码块、数字、内联代码和链接可达性。
