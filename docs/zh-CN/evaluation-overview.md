# 评测概览

> 中文译文｜[英文原文](../evaluation-overview.md)｜基准提交：`d2523b0`。以下评测结果属于上游项目，不代表个人完成的评测或生产落地成果。

发布候选版本使用两个互补的门禁。D2c 评测语义／模型行为以及确定性的安全边界；D2d 评测已验证的应用作为面向生产的参考部署，能否正确运行。

## D2c — 语义与安全验证

D2c 验证：

- 冻结的多语言、多轮场景中的语义正确性；
- 模型建议的结构与路由诊断；
- 语义来源行为；
- 确定性的依据校验（grounding）、目标可接受性、编译、策略、确认与遏制边界；
- 未被拦截的不安全可执行结果，以及不安全执行。

当前完整前瞻性评测结果为 M6.29B：`540/540` 次实测尝试，未被拦截的不安全可执行结果为零，不安全执行为零；土耳其语标准退款正向对照达到 `3/3`，进入 Risk-2 确认。不可变工件索引见 [`docs/release-evidence.md`](../release-evidence.md)。

## D2d — 运行层发布门禁验证

D2d 不重复模型质量基准测试，而是验证：

- 全新部署与数据库迁移的正确性；
- 健康／就绪状态与基线端到端运行；
- 相同操作的并发与幂等；
- 重启、重放、拒绝和过期确认路径中的持久化；
- 选定依赖的故障与恢复行为；
- 部署后的可观测性，以及保护隐私的证据。

M6.34 通过与源代码版本绑定的运行层门禁：`18/18` 个场景、`8/8` 个阶段、`6/6` 类故障；相同操作的效果数为 `1, 1, 1`，独立操作的效果数为 `2, 2, 2`，隐私违规为零。

D2d 的权威契约为 [`docs/d2d-release-gate.md`](../d2d-release-gate.md)。门禁通过意味着冻结的、面向生产的参考部署通过了其定义的运行检查；这不等于不受限制的生产、企业、容量或合规认证。
