## 阅读时必须区分的事实

1. **原仓库能力与个人贡献。** 原仓库已有 LangGraph、RAG、安全和幂等机制；本次工作是中文化与配套资料，不代表从零开发整个 Agent。
2. **演示与真实模型调用。** 静态投影、记录回放和 Fake 提供者都不等于真实模型刚执行了业务。
3. **本地验证与上游报告。** 原文中测试数、评测率和发布结论属于上游证据；不会自动成为你的测试结果。
4. **界面中文化与中文客服能力。** 本次不改变模型提示、英语政策语料、API 协议或业务工具；真实中文语义理解和检索效果需要另行验证。
5. **配置文件与最终运行配置。** Docker Compose 会覆盖部分 `.env` 设置，例如 backend 的 `OTEL_ENABLED=true`；不能只看 `.env` 判断 Docker 服务行为。

## 原文差异提示

上游 README 用“取消我的最新订单”解释目标解析，但 [严格语义目标文档](semantic-target-authority.md) 明确限制：`latest_order` 等符号引用可用于已认证的只读解析，取消或退款等破坏性意图需要经过依据校验的显式目标。译文保留各自原意。准备面试时，以当前契约、目标验证代码及实际测试为准，不把 README 的概念示例当作所有版本都允许的行为。
